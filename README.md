## 本地运行

每个文件是独立程序，请单独编译或运行。C++ 示例需要 `g++`，Python 示例需要 Python 3。

Windows PowerShell，从仓库根目录执行：

```powershell
g++ -std=c++17 -Wall -Wextra 2806.cpp -o 2806-local.exe
"2000" | .\2806-local.exe
# 输出：yes

"5" | python 2832.py
# 输出：120
```

Linux / macOS 的 C++ 运行方式为 `./2806-local`（编译时使用 `-o 2806-local`）。
